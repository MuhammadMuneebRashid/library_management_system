#  Library Management System

A simple Library Management System built with Python using Object-Oriented Programming (OOP) concepts. This project allows users to manage books through a menu-driven interface.

##  Features

-  Add new books
-  View all books
-  Borrow a book
-  Return a book
-  Exit the program

##  Concepts Used

- Python
- Object-Oriented Programming (OOP)
- Classes & Objects
- Constructors (__init__)
- Methods
- Lists
- Loops
- Conditional Statements (if, elif, else)
- Boolean Values (True / False)
- User Input

##  How to Run

1. Clone the repository:
   bash
   git clone https://github.com/your-username/Library-Management-System.git
   

2. Navigate to the project folder:
   bash
   cd Library-Management-System
   

3. Run the program:
   bash
   python library_management_system.py
